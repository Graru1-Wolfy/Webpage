# TF2 Hub

An unofficial fan page for Team Fortress 2. It lists maps, a jump catalog from the Tempus API, community servers, and a jump encyclopedia.

Community totals are a [SteamServerBrowser](https://www.steamserverbrowser.com/games/team-fortress-2) snapshot of all listed TF2 community servers. The server table is a separate Tempus and Jump Academy snapshot. Latency on that table is a regional estimate, not a measured ping, and tier is inferred from the server name. The jump catalog, records, and ranks are a Tempus snapshot. The page shows each snapshot date.

## Run locally

Open `index.html`, or serve the folder:

```bash
python3 -m http.server 8080
```
