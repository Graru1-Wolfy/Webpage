# Dynamic Colors

A single-page site that builds a color system from one seed color and applies it to a standard layout.

Pick a seed, switch between analogous, complement, triad, and mono harmonies, and toggle light or dark surfaces. Role swatches, the hue ramp, the sample app frame, and the CSS variables all update together. Select a swatch or the copy button to grab a hex value or the custom properties.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

In the repository settings, deploy Pages from the `main` branch at the site root. The page is static HTML, CSS, and JavaScript, so no build step is required.
