# Dynamic Colors

A lightweight GitHub-style webpage that generates dynamic color palettes in the browser.

## Features

- Modern layout inspired by GitHub's interface
- Generate harmonious HSL-based palettes
- Copy hex and HSL values with one click
- Lock individual swatches while regenerating
- Optional auto-rotate mode
- Light and dark theme support

## Run locally

```bash
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

## Deploy to GitHub Pages

Push this repository and enable GitHub Pages from the `main` branch (or your feature branch) using the root directory.
