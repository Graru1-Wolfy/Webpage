Features

Every accent, surface and gradient is derived from a single hue value using HSL.

🌓

Light & dark

Follows your system preference by default, with a manual toggle in the header.

💾

Remembers you

Your chosen hue and mode are saved locally, so the page looks the same next visit.

📱

Responsive

A mobile-first layout that adapts from phones to wide desktop screens.
