Jump servers

Loading Tempus and Jump Academy status.

Tempus and Jump Academy are listed separately. Rank limits such as top 100 belong to Tempus and are copied only when the server name says “Rank N”. Jump Academy has no player rank requirement. Latency is a regional estimate, not a measured ping. Tier is inferred from the server name. A password is shown only when a Steam server query reported one, and those servers are sorted to the bottom. Within the open servers, the order is region, then easy to advanced, then name.

Tempus

A top-100 filter keeps servers whose stated limit is 100 or looser, including servers that do not state a limit. It hides a tighter limit, such as top 50.
